# 🗳️ Smart Electronic Voting Machine (EVM)

## 📌 Overview

Smart EVM is a secure and intelligent electronic voting system designed to improve the reliability, transparency, and efficiency of digital elections. The system uses **AI-powered face authentication** to verify voters before allowing them to cast their votes, helping to prevent identity fraud, unauthorized access, and duplicate voting.

The platform provides separate functionalities for **voters and administrators**, including voter registration, face verification, secure voting, vote management, and election data management.

---

## 🚀 Technology Stack

Smart EVM is developed using a modern full-stack technology stack:

### Frontend
- **Framework:** React.js + Vite
- **Styling:** Tailwind CSS
- **Face Recognition:** TensorFlow.js with pre-trained face detection and recognition models

### Backend
- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB with Mongoose

---

## ✨ Key Features

### 🔐 AI-Based Face Authentication
- Uses AI-powered face recognition technology for secure voter verification.
- Allows only registered voters to access the voting system.
- Helps prevent identity fraud and multiple voting attempts.

### 👤 Voter Registration
- Enables users to register as voters with their personal information.
- Securely stores voter details in the database.
- Collects face data for authentication purposes.

### 🗳️ Secure Digital Voting
- Provides a simple and user-friendly voting interface.
- Allows verified voters to submit their votes securely.
- Maintains accurate and reliable voting records.

### 🛠️ Admin Dashboard
- Provides a dedicated dashboard for election management.
- Allows administrators to manage voters, monitor voting activities, and control system information.

### 📊 Vote Management
- Securely stores and manages voting records.
- Helps maintain organized election data and results.

### 📱 Responsive User Interface
- Fully responsive design for different screen sizes.
- Optimized for desktop, tablet, and mobile devices.

---

## 🎯 Project Objective

The main objective of Smart EVM is to develop a secure, reliable, and efficient electronic voting platform by combining modern web technologies with artificial intelligence.

The system aims to provide a transparent voting experience with enhanced security through AI-based face authentication, ensuring a safer and more trustworthy digital election process.
